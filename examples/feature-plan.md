# مثال: خطة ميزة (Example: feature plan)

> مثال خيالي لتطبيق مهام بسيط. الأسماء والملفات للتوضيح بس.
> A fictional example for a simple to-do app. Names and files are illustrative only.

**المطلوب:** المستخدم يقدر يضيف تاريخ استحقاق للمهمة، والمهام المتأخرة تظهر باللون الأحمر.
**الحجم:** متوسط (كذا مهمة في منطقة واحدة).

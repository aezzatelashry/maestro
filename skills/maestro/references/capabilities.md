# اللي البيئة بتوفّره في كل مرحلة

خريطة بتقول إيه اللي البيئة بتقدّمه لكل مرحلة، عشان المايسترو يستخدمه بدل ما يعيد بناءه أو يسيبه واقف. خريطة، مش ضمان: اللي موجود بيختلف بين الـ terminal والديسكتوب والجلسات السحابية، وبيتغيّر مع الإصدارات. قبل ما تعتمد على صف، اتأكد إن الأداة أو المهارة أو المنفّذ ظاهر فعلًا في الجلسة دي.

**Last checked:** الجدول ده منقول من fable-conductor 2.4.0 بتاريخ 2026-11-22 (جلسة Claude Code سحابية). ما اتفحصش في جلسة Maestro. لازم يتراجع على الجلسة الحالية قبل الاعتماد عليه، ويتحدّث وقت `evolve`.

| المرحلة | القدرة | بتتستخدم في | ملاحظة |
|---|---|---|---|
| الفهم | منفّذ Explore (بحث للقراءة بس) | «X فين» في ملفات كتير | ادّيه سؤال محدد واطلب `file:line`، على أرخص مستوى |
| الفهم | قواعد المشروع وملفات الذاكرة (`CLAUDE.md`، ملفات الحالة) | الأعراف، الممنوع، الشغل وقف فين | أعلى من الـ skill |
| القرار | Plan mode | موافقة المستخدم على نهج قبل أي تغيير | بيستنى إنسان: ما تستخدمهوش في جلسة فرعية بدون مراقبة |
| القرار | الأسئلة المنظّمة (اختيار من خيارات) | كل قرار بتاع المستخدم | التوصية الأول؛ المستخدم ما يكتبش |
| التقسيم | git worktrees، أو `isolation: "worktree"` في `Agent` | منفّذين بالتوازي مش لازم يتصادموا | worktree لكل منفّذ؛ نضّفها بعد الدمج |
| التوجيه | اختيار `model` في `Agent`، وتعريفات منفّذين بموديل ومجهود مثبّتين | اختيار المستوى لكل مهمة | منفّذ من غير مجهود مثبّت بيشتغل على مجهود الجلسة. منفّذين الـ plugin: `routing.md` |
| التوجيه | منفّذين متخصصين من المشروع أو plugin | شغل محتاج أعراف المشروع | النوع حسب التخصص، والموديل حسب الصعوبة |
| التوزيع | منفّذين وأوامر في الخلفية | أي حاجة بطيئة | بيجيلك إشعار لما تخلص؛ ما تعملش polling |
| التوزيع | مراسلة منفّذ شغّال أو خلّص (`SendMessage`) | التصحيحات والمتابعة | بيحافظ على السياق اللي اتدفع تمنه |
| التحقق | مراجعة الكود والأمان والتبسيط المدمجة | مرور مستقل على diff | مراجعة بأعلى مستوى بتفتح منفّذين كتير: لما تتطلب بس |
| التحقق | متصفح (لو مركّب) | تشوف تغيير واجهة اترسم | لو التطبيق يشتغل في البيئة |
| الدمج | Pull requests واشتراك في نشاطها | تسليم الشغل ومتابعة CI والمراجعات | الدفع والدمج حسب قواعد المشروع وموافقة المستخدم |
| التقرير | Artifacts | لوحة، تقرير هيتشاركه المستخدم | خاصة افتراضيًا |
| التسجيل | السجل و`lessons.md` | تحسين التوجيه من الأدلة | `scripts/ledger.py` |
| التوفير | ضغط المحادثة عند وقفة طبيعية؛ جلسة جديدة لكل مرحلة | جلسات طويلة، كل turn بيبعت المحادثة كلها | احفظ الحالة الأول |
| التوفير | شاشة الاستهلاك (`/usage`) | صرف المستخدم الفعلي، بما فيه المايسترو | السجل ما بيشوفش tokens المايسترو |
| التكرار | مهام مجدولة؛ loop بإيقاع ذاتي | مراجعات دورية وفحوص | أنشئ اللي المستخدم طلبه بس |
| التوسّع | Workflows بسكربتات متعددة المنفّذين | توزيع ضخم جدًا | لو المستخدم اختارها صراحة؛ المراحل الرخيصة على مستويات رخيصة |
| الصيانة | سكربت الجرد | مهارات مكررة وhooks أول جلسة | `scripts/inventory.py`، للقراءة بس |
